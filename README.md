# ❄ Rack Calculation — расчет холодильных агрегатов

Веб-приложение для подбора и расчета холодильных агрегатов (компрессорно-ресиверных блоков):
подбор компрессоров по полиномам AHRI/EN12900, расчет трубопроводов, автоподбор опций,
формирование коммерческого предложения (EUR, без НДС) и производственной спецификации.

Стек: **Node.js + Express + SQLite (встроенный `node:sqlite`) + EJS + Telegram-бот**.

## Возможности

1. **Авторизация и роли** — вход, саморегистрация с подтверждением администратором (Telegram-бот или веб-админка).
2. **Каталог** — производители (Xecom, Bitzer, Copeland, Refcomp, Ridan, Invotech), хладагенты (R404a, R507a, R410a, R32, R449b).
3. **Ввод параметров** — t кипения, t конденсации, хладагент, требуемая мощность, перегрев/переохлаждение.
4. **Подбор компрессоров** — автоматический по мощности либо ручной выбор модели и количества. Пересчет по полиномам AHRI: Q, мощность, ток, массовый расход, COP.
5. **Расчет трубопроводов** — всасывание / нагнетание / жидкость, индивидуальные и магистральные линии; подбор дюймовых диаметров по скоростям (12/12/1.2 м/с).
6. **Опции-чекбоксы** — автовключение по режиму работы (зимняя опция, маслоотделитель, отделитель жидкости, ресивер и т.д.), подбор артикулов из каталога.
7. **Коммерческое предложение** — калькуляция (материалы + мелочь 5% + работы 30% + профит 15%), клиентская скидка, печатная форма КП.
8. **Производственная спецификация** — полная BOM по номеру КП после утверждения, экспорт CSV.

## Установка и запуск

```bash
npm install
copy .env.example .env      # Windows (или: cp .env.example .env)
npm run seed
npm start
```

Откройте http://localhost:3000

**Администратор по умолчанию:** `admin@local` / `admin123` (смените после первого входа).

## Настройка Telegram-бота

1. Получите токен у @BotFather (`/newbot`).
2. Узнайте chat_id у @userinfobot.
3. Впишите в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ADMIN_CHAT_ID=123456789
   ```
4. Перезапустите приложение — при регистрации клиента админу придёт карточка с кнопками «Одобрить/Отклонить».

Без токена бот отключится, одобрение доступно в веб-админке: **Пользователи**.

## Импорт каталога компрессоров из Excel

1. Сгенерируйте шаблон: `npm run template` → `data/import-template.xlsx`.
2. Формат совместим с листами `Refcomp_polynom` / `Xecom_polynom` из «База данных.xlsx»:
   - колонки 15–24 — коэффициенты мощности `P_C1..P_C10`;
   - колонки 45–54 — массовый расход `M_C1..M_C10` (опционально);
   - колонки 55–64 — **холодопроизводительность** `C_C1..C_C10`;
   - колонка 65 — множитель (1000 — если значения в Вт; 1 — если в кВт).
3. Админка → **Импорт Excel** → выберите производителя и загрузите файл.

```

services/refrigerants.js   — свойства хладагентов, точки цикла
services/selection.js      — полиномы AHRI, автоподбор компрессоров
services/piping.js         — расчет трубопроводов
services/options.js        — правила автовключения и подбор компонентов
services/pricing.js        — калькуляция, номера КП
services/calc.js           — оркестратор полного расчета

views/                     — EJS-шаблоны

```

## Бизнес-логика цены

Материалы (компрессоры + корпус + компоненты + фиксированные позиции)
→ Мелочь 5% → Работы 30% → Профит 15% → Итого без НДС → скидка клиента (задаёт админ) → ВСЕГО.

Все цены в **EUR без НДС**.

## Технические допущения

- Свойства хладагентов (P, ρ, h) — табличные данные с линейной интерполяцией; для финальной верификации используйте CoolProp / данные производителей.
- Характеристики компрессоров рассчитываются строго по коэффициентам AHRI/EN12900 из каталога (экстраполяция за пределы диапазонов t кип/конд запрещена).
- Демо-данные компрессоров содержат реальные полиномы Refcomp/Xecom (выборка моделей); полный каталог загружайте через Excel-импорт.
- Цены компонентов в демо-данных условные — замените на актуальные через админку/импорт.
